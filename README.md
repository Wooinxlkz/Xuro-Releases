# Xuro Releases

Official public release repository for **Xuro**, a local-first Markdown notes app for Windows.

> **Source code is not published in this repository.** The Xuro source repository is private. This repository exists only for official public releases, installers, release notes, and legal notices.

## Download

Download Xuro only from the official website or this repository's GitHub Releases page.

## What is Xuro?

Xuro is a local-first Markdown notes application for Windows. Your notes remain ordinary `.md` files in a folder you control, with features including a rich Markdown editor, folders, search, tasks, bookmarks, graph view, library, online manga, plugins, canvas, PDF export, and optional Xuro Cloud publishing.

## Repository purpose

This repository intentionally contains **no Xuro source code**. It is used to publish:

- Windows installers
- GitHub release metadata and release notes
- Public legal notices
- Third-party license notices
- Security reporting information

The application source code, development history, and private build configuration are maintained separately.

## Releases

Each release should include the version number, release notes, and the official installer artifact. Release assets are provided by the Xuro publisher.

## Authenticity

Before installing, verify that the release comes from the `Wooinxlkz/Xuro-Releases` repository and that the download was reached through https://usexuro.app or this repository's Releases page.
